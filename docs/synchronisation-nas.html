Synchroniser WorkLog avec ton NAS

Guide pour un Synology DS224+ (DSM 7.2) avec PocketBase. Tes données ne vont que sur ton NAS : rien n'est écrit dans le code de l'app, sur GitHub ou chez un service tiers.

Comment ça marche. PocketBase est un petit serveur (un seul programme) qui tourne dans Container Manager sur ton NAS. WorkLog y garde un enregistrement par compte, avec toutes tes données (séries, favoris, séances, notes, séances types, programmations, poids du corps). L'app envoie tes modifications quelques secondes après chaque changement et récupère celles faites ailleurs quand elle s'ouvre. Si deux appareils ont changé en même temps, les données sont fusionnées : rien n'est perdu.

Limite d'iOS : une app web ne travaille pas quand elle est fermée. La synchronisation se fait donc quand WorkLog est ouverte.

1. Installer PocketBase sur le NAS

  1. Dans DSM, ouvre le Centre de paquets et installe Container Manager (le DS224+ le prend en charge).
  2. Dans File Station, crée le dossier docker/pocketbase (le dossier partagé docker existe en général après l'installation de Container Manager), puis le sous-dossier pb_data dedans.
  3. Ouvre Container Manager › Projet › Créer. Nom : pocketbase. Chemin : /docker/pocketbase. Source : Créer docker-compose.yml, et colle : 
    services:
  pocketbase:
    image: ghcr.io/muchobien/pocketbase:latest
    container_name: pocketbase
    restart: unless-stopped
    ports:
      - "8090:8090"
    volumes:
      - ./pb_data:/pb_data
    environment:
      TZ: Europe/Paris
  4. Termine l'assistant : le projet démarre. Dans Container › pocketbase › Journal, PocketBase affiche une adresse du type http://0.0.0.0:8090/_/#/pbinstal/… : ouvre-la en remplaçant 0.0.0.0 par l'adresse locale du NAS (par exemple http://192.168.1.20:8090/_/…) et crée ton compte administrateur (superuser).

L'image ghcr.io/muchobien/pocketbase est une image communautaire très utilisée qui suit les versions officielles de PocketBase.

2. Préparer PocketBase pour WorkLog

  1. Dans le tableau de bord PocketBase (http://IP-du-NAS:8090/_/), va dans Settings › Import collections.
  2. Colle le contenu du fichier pocketbase-worklog.json (il est dans ce même dossier docs du dépôt), puis Review et Confirm. Ça crée la collection worklog : un enregistrement par compte, que seul ce compte peut lire et modifier.
  3. Interdis la création de comptes depuis l'extérieur : Collections › users › ⚙ › API Rules, règle Create : clique sur le cadenas pour la réserver aux superusers, puis enregistre.
  4. Crée ton compte : Collections › users › New record, avec ton e-mail, un mot de passe solide, et coche Verified.
  5. Facultatif : dans Collections › users › ⚙ › Options › Auth token, mets une durée plus longue (par exemple 2592000 secondes, soit 30 jours). WorkLog renouvelle son jeton chaque jour où tu l'ouvres ; tu n'auras à te reconnecter que si tu ne l'ouvres pas pendant cette durée.

3. Rendre le NAS joignable en HTTPS

WorkLog est servie en HTTPS par GitHub Pages : le navigateur refuse qu'elle parle à un serveur en simple HTTP. Il faut donc une adresse en https:// vers PocketBase. Deux possibilités :

A. Tailscale (recommandé : rien n'est ouvert sur Internet)

  1. Installe le paquet Tailscale sur le NAS (Centre de paquets) et l'app Tailscale sur l'iPhone, avec le même compte.
  2. Dans la console Tailscale (DNS), active MagicDNS et HTTPS Certificates.
  3. Active le service SSH du NAS (Panneau de configuration › Terminal et SNMP), connecte-toi en SSH et lance : 
    sudo tailscale serve --bg 8090
    Le NAS répond alors à une adresse du type https://ds224.ton-reseau.ts.net, seulement pour tes appareils connectés à Tailscale.
  4. C'est cette adresse que tu mets dans WorkLog. La synchronisation marche dès que Tailscale est actif sur l'iPhone, à la maison comme dehors.

B. Proxy inversé de DSM avec un certificat Let's Encrypt

  1. Panneau de configuration › Accès externe › DDNS : crée une adresse, par exemple ton-nom.synology.me, en cochant l'obtention d'un certificat Let's Encrypt.
  2. Panneau de configuration › Portail de connexion › Avancé › Proxy inversé › Créer : source HTTPS, nom d'hôte ton-nom.synology.me, port 8443 (par exemple) ; destination HTTP, localhost, port 8090.
  3. Sécurité › Certificat › Paramètres : associe le certificat Let's Encrypt à ce proxy inversé.
  4. Sur ta box, redirige le port 8443 vers le NAS. L'adresse à mettre dans WorkLog est https://ton-nom.synology.me:8443.

Avec cette méthode, PocketBase est joignable depuis Internet (protégé par ton mot de passe). Garde la création de comptes verrouillée (étape 2.3) et un mot de passe solide.

4. Connecter WorkLog

  1. Dans WorkLog : menu de l'accueil › Réglages › Synchronisation avec ton NAS.
  2. Adresse du serveur (celle de l'étape 3), e-mail et mot de passe du compte créé à l'étape 2.4, puis Se connecter.
  3. La première synchronisation envoie tes données. Sur un autre appareil, la même connexion les récupère (et fusionne avec ce qu'il y a déjà).

Ce qui reste sur le téléphone : l'adresse du serveur, ton e-mail et un jeton de connexion. Le mot de passe n'est pas enregistré.

Boutons utiles : « Synchroniser maintenant », « Remplacer par les données du NAS » (les données du NAS écrasent celles du téléphone), « Se déconnecter » (tes données restent sur le téléphone).

À savoir : une série supprimée sur un appareil pendant qu'un autre appareil a aussi été modifié peut revenir lors de la fusion. Supprime-la à nouveau si besoin.

5. Sauvegarder le NAS lui-même

Toutes les données PocketBase sont dans /docker/pocketbase/pb_data. Ajoute ce dossier à Hyper Backup pour en garder une copie. L'export complet de WorkLog (Historique › Exporter) reste aussi disponible.
